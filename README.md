# ☕ Trilha Java

Repositório criado para reunir algumas atividades e exercícios desenvolvidos durante os estudos da disciplina Linguagem de Programação Orientada a Objetos (LPOO) em Java.

## 📚 Conteúdo

Este repositório contém exemplos práticos e atividades abordando conceitos fundamentais da linguagem Java e da orientação a objetos, incluindo:

* 🔹 Fundamentos da linguagem Java
* 🔹 Classes e Objetos
* 🔹 Encapsulamento
* 🔹 Associações entre objetos
* 🔹 Herança
* 🔹 Polimorfismo e Sobrescrita de Métodos
* 🔹 Organização de projetos
* 🔹 Boas práticas de modelagem

## 🗂️ Estrutura do Repositório

As atividades estão organizadas em diretórios independentes, cada um explorando um tema específico:

| Pasta                      | Tema                                       |
| -------------------------- | ------------------------------------------ |
| 📘 `ATIVIDADE_1`           | Exercícios introdutórios de Java           |
| 📗 `ATIVIDADE_3`           | Classes, objetos e modelagem               |

## ⭐ Destaque: atividadeMVC

O projeto **`atividadeMVC`** demonstra a aplicação do padrão arquitetural **MVC (Model-View-Controller)**, amplamente utilizado no desenvolvimento de software.

### 🧩 Organização do Projeto

* 📦 **Model** → entidades e regras de negócio
* 🖥️ **View** → interação com o usuário
* 🎮 **Controller** → controle do fluxo da aplicação
* 🗄️ **DAO** → acesso e manipulação de dados
* 🔧 **Util** → recursos auxiliares e infraestrutura

### 🎯 Objetivo

Demonstrar a separação de responsabilidades entre as camadas da aplicação, tornando o código mais organizado, reutilizável e fácil de manter.

## 🚀 Objetivo Geral

Este repositório possui finalidade educacional e registra a evolução dos estudos em **Java** e **Programação Orientada a Objetos**, servindo como material de consulta, prática e aprendizado contínuo.

> 💡 "Aprender programação é construir conhecimento um projeto por vez."
